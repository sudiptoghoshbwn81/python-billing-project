# Python Billing Application

## Project Overview
A Python-based billing application that uses MySQL for database operations and QR code scanning to support product identification during billing.

## Technologies Used
- Python
- MySQL
- OpenCV 
- Pyzbar
- Streamlit
  
## Project Files
- `billing_app.py` — Main billing application.
- `QR_Code_Scanner.py` — QR code scanning functionality.

## Setup Instructions
1. Install Python.
2. Install Git and clone this repository.
3. Install the required Python packages.
4. Configure your MySQL connection using your own local credentials.
5. Create or configure the required database and tables.
6. Run the main application using the appropriate command.

## Note
Database setup and local configuration may be required before running the application.
